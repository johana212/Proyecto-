¿Qué es la arquitectura del computador?

Es la forma en que se organizan los componentes de un equipo para recibir, procesar y entregar información de manera eficiente.

⚙️

Componentes principales

🧠 CPU
🧩 RAM
💽 SSD
🛣️ Placa
⌨️ Entrada/Salida
🖥️

¿Qué es un sistema operativo?

Es el software principal que permite que el usuario y los programas interactúen con el hardware de manera ordenada y segura.

🔐

Funciones del sistema operativo

Administración de memoria Gestión de archivos Control de procesos Administración de dispositivos Seguridad
🌐

Sistemas operativos más utilizados

🪟 Windows
🐧 Linux
🍎 macOS
Sistemas de numeración
🔢

Sistema Decimal (Base 10)

Utiliza diez símbolos: 0, 1, 2, 3, 4, 5, 6, 7, 8 y 9.

Ejemplo: 245
0 1

Sistema Binario (Base 2)

Solo emplea dos símbolos: 0 y 1, muy usado en computación.

Ejemplo: 1011₂
🧮

Sistema Octal (Base 8)

Usa ocho símbolos, desde 0 hasta 7, y resulta práctico en sistemas digitales.

Ejemplo: 37₈
#

Sistema Hexadecimal (Base 16)

Emplea dieciséis símbolos, incluyendo letras A a F para valores mayores.

Ejemplo: 2F₁₆
