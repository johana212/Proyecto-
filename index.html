Conceptos clave de la unidad

Esta unidad permite comprender cómo está organizada una computadora, cómo interactúan sus componentes y por qué el sistema operativo es esencial para coordinar tareas, recursos y seguridad.

Arquitectura del computador

Es la organización interna del equipo que permite recibir, procesar, almacenar y entregar información de manera eficiente. Incluye componentes como la CPU, la RAM, el almacenamiento, la placa madre y los dispositivos de entrada y salida.

¿Qué es un sistema operativo?

Es el software principal que hace posible que el usuario y las aplicaciones interactúen con el hardware. Administra procesos, memoria, archivos, dispositivos y seguridad.

Funciones del sistema operativo

Sistemas operativos

Windows

Windows es un sistema operativo desarrollado por Microsoft, muy utilizado en hogares, oficinas y escuelas debido a su interfaz intuitiva, compatibilidad amplia con software y facilidad de uso para personas de diferentes niveles.

Linux

Linux es un sistema operativo libre y de código abierto basado en Unix, conocido por su estabilidad, seguridad, flexibilidad y gran uso en servidores, desarrollo web y entornos técnicos avanzados.

macOS

macOS es el sistema operativo creado por Apple para sus computadoras Mac, reconocido por su diseño elegante, desempeño estable y excelente integración con otros dispositivos del ecosistema Apple.

Android

Android es un sistema operativo móvil basado en Linux, pensado para teléfonos, tablets y otros dispositivos inteligentes. Se caracteriza por su personalización, variedad de aplicaciones y gran alcance en el mercado móvil.

iOS

iOS es el sistema operativo móvil de Apple para iPhone y iPad. Está enfocado en la privacidad, la simplicidad, la seguridad y una experiencia uniforme, ideal para usuarios que prefieren estabilidad y diseño cuidado.

🔢

Sistemas de numeración

Sistema decimal

Definición: es el sistema más utilizado por las personas y se basa en 10 símbolos.

Características: usa potencias de 10 y es muy intuitivo para la vida cotidiana.

Ejemplo: 245 = 2×10² + 4×10 + 5.

Sistema binario

Definición: utiliza solo 0 y 1, lo que permite representar información digital.

Características: forma la base de la computación porque los circuitos electrónicos reconocen dos estados.

Ejemplo: 1011₂ = 11 en decimal.

Sistema octal

Definición: se basa en 8 símbolos y permite representar grupos de bits de forma compacta.

Características: es útil para simplificar representaciones binarias y se relaciona con sistemas antiguos.

Ejemplo: 37₈ = 31 en decimal.

Sistema hexadecimal

Definición: usa 16 símbolos, incluyendo letras A a F para valores mayores.

Características: es muy usado en programación, redes y diseño web para expresar datos de manera breve.

Ejemplo: 2F₁₆ = 47 en decimal.

Sistema Base Símbolos Uso principal
Decimal 10 0-9 Uso cotidiano
Binario 2 0 y 1 Computación
Octal 8 0-7 Representación compacta
Hexadecimal 16 0-9 y A-F Programación y redes

Aplicaciones reales

El sistema decimal se usa en la vida diaria para contar, medir y calcular; el binario es indispensable en la informática; el octal aparece en representaciones técnicas y el hexadecimal se utiliza constantemente en colores, memoria y programación.
